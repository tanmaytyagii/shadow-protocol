# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be respectful and constructive in issues, pull requests and reviews.
- Critique code and ideas, not people.
- No harassment, personal attacks, discriminatory language or unwelcome sexual attention.
- Don't publish anyone's private information without their permission.

## Enforcement

The maintainer ([@tanmaytyagii](https://github.com/tanmaytyagii)) may edit or remove comments, commits, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem privately, use the contact options on the maintainer's GitHub profile. Reports are handled confidentially.
